# Mara Fitness — No-login edition

Mara Fitness is a standalone fitness tracker. **There is no login, Gmail connection, Supabase setup, or cloud account.**

## Start using it
1. Extract `Mara_Fitness_Offline.zip`.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. Start recording workouts, meals, tea/coffee/milk, body weight and waist measurements.

## Data storage
- Records are saved in the browser's local storage on the device/browser where you use the app.
- No account is needed and the app does not send your records to a server.
- Do not clear browser site data if you want to keep your records.
- Use **Excel Centre → Download full Excel workbook** regularly to back up your data.
- Use **Import Excel workbook** to restore or merge a previously exported Mara Fitness workbook.
- To use another device, export the workbook from the first device and import it on the second.

## Included features
- Weekly workout plan with editable exercises, sets, reps, actual weights and completion ticks.
- Meal journal with calories, protein, carbs and fat, including tea, coffee and milk.
- Body weight and waist check-ins.
- Dashboard and progress history.
- Excel import/export with separate sheets for workouts, exercise sets, meals, body metrics and profile summary.

Exercise photos are remote image links and require an internet connection. The app itself and local data entry work without a login. The Excel library is loaded from a CDN, so Excel import/export requires an internet connection.
